## 8. コード

`インラインのコード` を文の中に置きます。``バッククォートを含む `コード` `` も書けます。

字下げによるコードです。

    これは4つの空白で字下げしたコードです。
    そのままの形で出ます。

言語を指定したコードです。

```rust
fn main() {
    // 速さは、削った分だけ手に入る
    let files: Vec<&str> = vec!["a.md", "b.csv"];
    for f in &files {
        println!("開く: {f}");
    }
}
```

```python
def 起動時間(回数: int) -> float:
    """何度か測って、真ん中の値を返す。"""
    values = [measure() for _ in range(回数)]
    return sorted(values)[len(values) // 2]
```

```json
{
  "theme": "light",
  "font_size": 16,
  "enable_math": true
}
```

